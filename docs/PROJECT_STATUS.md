# ReStory: состояние проекта

Обновлено: 14.11.2026. Репозиторий: https://github.com/AzaKail/re-story

## 1. Что за проект

Кейс NASA Space Apps Challenge: «Abandoned but not Forgotten: Storytelling about NASA's Discarded Equipment on the Moon and Mars».

Сайт-музей в браузере. Посетитель видит космос с Луной и Марсом, на них отмечены аппараты NASA, которые там остались навсегда. Выбираешь аппарат: камера подлетает к нему, а кнопка «Узнать больше» открывает раздел музея с его историей. Справа внизу чат-бот AIstronaut отвечает на вопросы.

Главная идея кейса: «очеловечить технику». Аппарат сам рассказывает, зачем его создали, что он пережил и почему замолчал.

## 2. Как запустить у себя

Нужны Python 3.12+, git, PostgreSQL. Для чата ещё Ollama.

1. Создать пустую базу `bd_re_story` в PostgreSQL.
2. Выполнить:
   ```
   git clone https://github.com/AzaKail/re-story.git
   cd re-story
   python -m venv .venv
   .venv\Scripts\activate            (macOS / Linux: source .venv/bin/activate)
   pip install -r requirements.txt
   copy .env.example .env            (macOS / Linux: cp .env.example .env)
   ```
3. В `.env` вписать пароль PostgreSQL в `DB_PASSWORD`.
4. Выполнить:
   ```
   python manage.py migrate            (заодно заполняет каталог аппаратов)
   python manage.py load_knowledge
   python manage.py runserver
   ```
5. Открыть http://127.0.0.1:8000/. Адрес с `?lang=ru` или `?lang=kk` сразу открывает нужный язык, `#mars` открывает Марс.

Для чата: установить Ollama и скачать модели `ollama pull gemma4:e2b` и `ollama pull nomic-embed-text`.

Если `activate` пишет, что выполнение сценариев отключено: один раз выполнить `Set-ExecutionPolicy -Scope CurrentUser RemoteSigned`.

## 5. Что уже сделано

**Основа**
- Проект Django, база PostgreSQL, настройки через `.env` (пароли в git не попадают).
- Документация: `docs/documentation.md` (на английском), журнал этапов `docs/JOURNAL.md`, реестр источников `docs/SOURCES.md`.

**3D-космос**
- Звёзды, Солнце как источник света, Луна, Марс и Земля с картами NASA.
- Карты Луны и Марса в трёх размерах: 2k грузится сразу, детальная 8k (4k на телефоне) подгружается фоном только для текущей планеты.
- Вращение мышью и пальцами, медленное автовращение, которое останавливается, когда человек берёт управление.
- Переключатель Луна / Марс с перелётом камеры. Марс стоит далеко от Луны и Земли.
- Нельзя приблизиться ближе, чем вид на объект: ближе карта всё равно размыта.
- На фоне Меркурий, Венера, Юпитер, Сатурн, Уран, Нептун: настоящие фото NASA, всегда повёрнуты к экрану.
- Мягкая подсветка от камеры, чтобы объект было видно и на ночной стороне.

**Сценарий посетителя**
- Слева панель «Объекты» со списком того, что есть на этой планете. Её можно свернуть.
- Клик по объекту: камера подлетает по дуге к точке, там метка. Внизу полоска: «Узнать больше» и крестик (Esc тоже закрывает).
- «Узнать больше»: камера ныряет в точку, экран темнеет, открывается музей.
- Музей: отдельный экран со своей прокруткой. Назад в 3D только кнопкой «3D-версия», прокруткой туда не попасть.

**Языки**
- Переключатель EN / RU / KZ. Без перезагрузки, выбор запоминается. Чат тоже переключается вместе с сайтом.

**Скорость**
- Пока открыт музей, 3D не рисуется.
- Если кадров меньше 40 в секунду, качество картинки снижается автоматически.
- Three.js и все текстуры лежат в проекте, интернет на показе не нужен.

**Чат-бот (Дмитрий)**
- Окно чата AIstronaut, ответы потоком, история в пределах вкладки.
- Отвечает по документам, которые загружаются в админке (`/admin/`).
- Три языка, следит за переключателем языков сайта.

## 6. Каталог и музей (готово)

- **Каталог:** 15 аппаратов NASA в базе (4 на Луне, 7 на Марсе, 4 в дальнем космосе): рассказ от первого лица, факты, даты, координаты, фото NASA, сестринские миссии, ссылка на источник, переводы ru и kk. Данные лежат в `data/artifacts.json`, в базу их загружает `python manage.py seed_catalog`. Править можно в админке.
- **API:** `/api/bodies/`, `/api/artifacts/?body=moon`, `/api/artifacts/<код>/`.
- **Музей:** «Узнать больше» открывает страницу аппарата. Внизу страницы другие аппараты на этом теле и рассказ о самом теле.
- **Чат:** знает тексты команды и весь каталог на трёх языках (`python manage.py load_knowledge`). Кнопка «Спросить аппарат» открывает чат с готовым вопросом.

- **«Тогда и сейчас»:** у 6 аппаратов рядом с архивным фото современный снимок места с орбиты (LRO, HiRISE) или с ровера.
- **«О проекте»:** открывается кликом по названию ReStory слева вверху.

Что ещё заглушки:
- На месте аппаратов оранжевые метки: 3D-модели не используем, жюри не дало разрешения.
- Аппараты на Церере, Эросе и в дальнем космосе есть в каталоге, но не в 3D-сцене.

## 8. Идеи, которые помогут победить

- **«Тогда и сейчас».** Снимки мест посадки с орбиты: камера LRO видит посадочные ступени Apollo и колеи луноходов, HiRISE видит Spirit, Phoenix, InSight. Доказательство «мы до сих пор их видим».
- **«Последний сигнал».** Таймлайн аппарата: запуск, посадка, работа, тишина. Только проверенные даты. Честно помечаем мифы: фраза Opportunity «My battery is low and it's getting dark» на самом деле пересказ журналиста, а не сообщение ровера.
- **Таймлайн 1966-2024:** ползунок, аппараты появляются в год посадки и гаснут, когда замолкают.
- **Режим Artemis:** охранные зоны вокруг мест Apollo по рекомендациям NASA 2011 года. Связь с сегодняшними миссиями.
- **«Оставить благодарность»:** общий счётчик у каждого аппарата.
- **Значок «Данные NASA»** со ссылкой у каждого факта.

## 9. Договорённости команды

- **Коды аппаратов** одни на всех: например `apollo-11`, `spirit`, `ingenuity`. По ним связаны 3D, музей и чат.
- **Данные только NASA.** Каждая картинка, модель, факт: строка в `docs/SOURCES.md` (откуда, лицензия, где используется). Ничего не выдумываем: нет источника, значит, поле пустое.
- **Тексты интерфейса** сразу на трёх языках. Английский главный. Строки 3D-части в `static/js/i18n.js`, у всех языков одинаковые ключи.
- **После каждого изменения** обновляется `docs/documentation.md` (на английском): что изменили, зачем, как пользоваться.
- **Секреты** (пароли, ключи) только в `.env`, он не попадает в git.

## 10. Риски и открытые вопросы

- **Ссылка для жюри.** Показ идёт с ноутбука. Если проект будут смотреть онлайн после демо, нужна публичная версия (хотя бы без чата) или видео. Проверить правила сдачи на сайте Space Apps.
- **Чат на показе.** Перед выступлением один раз задать боту вопрос, чтобы модель загрузилась в память. Первый ответ после запуска может идти долго.
- **Казахский перевод** надо вычитать человеку, который хорошо знает язык.
- **Факты.** Каждую дату и цифру сверять с NSSDCA и science.nasa.gov. Одна ошибка подрывает доверие жюри.
- **Цвета чата и сайта:** у чата синий акцент, у сайта янтарный. Стоит выровнять.
